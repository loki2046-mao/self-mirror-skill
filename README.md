# Self Mirror / 自我画像生成器

## 定位

帮 AI agent 更了解用户，不是给用户做一次性人格测试。

核心框架三层：
- **心理学层**（大五人格 OCEAN、精神分析、荣格人格面具/阴影、依恋理论、CBT认知扭曲）——从文本可量化分析
- **实用哲学层**（尼采主人道德、斯多葛控制圈）——挖人性内核和处世底色
- **文学人格镜像**（太宰治/村上春树/鲁迅/加缪风格对标）——快速定位精神气质

目标输出：① 真实人性底层 ② 行为模式惯性与短板 ③ 可落地的改造方案

---

## 不该用的情况

- 用户需要心理疾病诊断
- 分析他人隐私或操控他人
- 用户只是普通闲聊，没有明确请求自我分析
- 用星座、八字做人格判断（除非明确娱乐）

---

## 核心原则

1. 只基于文本证据分析，不做医学诊断
2. 区分长期人格底色（OCEAN）和短期阶段状态
3. 所有判断必须给出文本证据，不凭空下结论
4. 用「从这批材料看」「更像是」「可能说明」——避免绝对化
5. 荣格阴影、弗洛伊德潜意识部分要说出来，但不吓人，不玄学
6. 最后必须落到行动，给可执行的改造方案
7. 最后生成一段可写入 agent memory 的用户摘要

## 禁止输出

「你有抑郁症/焦虑症」「你是讨好型/自恋型/回避型人格」「你潜意识里一定是……」「你内心深处其实……」「你没救了」

---

## 分析框架详解

### 框架一：大五人格 OCEAN（人格底色，最适合文本量化）

从文本里逐维度找证据：

- **开放性（O）**：用词抽象/具体、是否追求新概念、多领域涉猎程度
- **尽责性（C）**：做事规划逻辑、收尾习惯、自我要求表述、能不能扛完一件事
- **外倾性（E）**：聊天主被动、社交措辞冷热、能量来源是独处还是人群
- **宜人性（A）**：吵架/协商方式、对他人需求的优先级、边界感
- **神经质（N）**：情绪化用词频率、焦虑句式、抱怨/自我否定的密度

每个维度：高/中高/中/中低/低，并给出文本证据。天生底色 vs 可后天修正的部分都要说清楚。

### 框架二：荣格人格面具 vs 阴影

- **面具**：公开文字、对外说话方式、刻意维持的人设
- **阴影**：私下聊天、失控时刻、吐槽、不敢承认的真实渴望

从语料里拆分两层，找出「你对外维持的形象」和「你压下去没承认的部分」，帮用户接纳而非批判。

### 框架三：精神分析（潜意识信号）

从文本里抓：
- 反复出现的关键词/情绪词（执念信号）
- 刻意回避的话题
- 自我辩解的固定句式
- 高频自嘲、优越感、委屈感表达
- 防御机制：合理化、转移、压抑

### 框架四：依恋模式

从说话方式、相处描述判断：
- **安全型**：相信关系，不过度焦虑也不回避
- **焦虑型**：怕被抛弃，需要频繁确认，依赖感强
- **回避型**：情感疏离，主动保持距离，压制需求

对人际关系、亲密感、AI依赖模式的解释特别有用。

### 框架五：CBT认知扭曲

找出文本里的思维 bug：
- 非黑即白
- 过度概括（"我总是/从来"）
- 灾难化
- 完美主义
- 情绪化推理（"我感觉很糟，所以一定很糟"）
- 自我否定

每个扭曲点给出替代表达和可执行修正方式。

### 框架六：尼采——主人道德 vs 奴隶道德

从文字里判断：骨子里是以自我价值为核心，还是活在他人评价和讨好里。
看：委屈表达、迎合语气、自我妥协句式，还是笃定自我、不解释、直接行动。

### 框架七：斯多葛控制圈

从文字里找：有没有过度纠结自己控制不了的事（他人反应、数据、别人的评价）？
指出哪些焦虑是无效的，只把能量放在可控范围内。

### 框架八：文学人格镜像（精神气质对标）

从行文风格、处世态度、情绪密度，快速对标：
- **太宰治**：敏感内耗、高共情、自我否定、悲剧感
- **村上春树**：疏离独处、低欲望、内心有自己秩序、清醒但不激烈
- **鲁迅**：批判清醒、看透人性、疏离感、不妥协
- **加缪**：接受荒诞、不躺平也不内卷、冷静行动

## 执行流程

**Step 1**：识别输入材料类型（聊天记录/日记/文章/AI对话/混合语料），说明置信度

**Step 2**：提取文本信号
- 高频词、情绪词、重复句式
- 回避话题、防御机制、自嘲/优越感表达
- 行动模式、卡点、决策方式

**Step 3**：八个框架逐一分析（按重要性排序，不是每个框架都要平均篇幅）

**Step 4**：整合输出三块核心结论
① 真实人性底层（你是谁，比你以为的更准）
② 行为惯性地图（如何启动、兴奋、卡住、逃避、恢复）
③ 可落地改造方案（具体到日常说话、思考、做事怎么改）

**Step 5**：生成 agent memory 摘要

这一节是重点。不是总结，是你自己看不见的角落。3-5条，每条要让人看完说"哇你怎么知道的"。

---

**行为惯性地图**

- 你如何启动一件事：
- 你如何进入兴奋：
- 你如何卡住：
- 你如何逃避或转移：
- 你如何恢复行动力：

---

**可落地改造方案**

只给 3 条，每条：问题 → 日常可执行的具体改法（不是鸡汤）

---

**给 AI agent 的用户画像摘要**

分门别类，结构化输出，可直接存入 memory。不写成一段话。

固定结构如下：

**基本信息**
- 姓名/昵称、年龄、性别（如已知）
- 高产时段
- 恢复方式

**人格底色（OCEAN）**
- 每个维度一行：维度：得分——一句话说明

**核心驱动与阻力**
- 驱动：什么点燃ta
- 阻力：什么让ta卡住
- 兴奋触发：什么让ta进入高速状态

**荣格面具/阴影**
- 面具：ta对外维持的形象
- 阴影：ta没承认的真实需求

**依恋模式**
- 类型 + 在AI关系中的表现

**协助ta的方式**
- 列出3-5条具体可操作的原则

**注意事项**
- 列出2-4条容易踩的坑或需要特别记住的细节

---

## 输出风格

- 中文，自然直接，有洞察
- 结论锋利，表达有边界
- 不堆理论名词，不鸡汤，不吓人，不玄学
- 「你没意识到的那几件事」这节要真的说出来，不只是整理已知信息
- 最后必须落到行动

---

## 语料质量评估（前置步骤）

在正式分析之前，先评估用户提供的语料能支撑多深的分析。评估后告诉用户当前材料的分析深度上限，并建议补充什么能让结果更准。

### 评估维度

| 维度 | 说明 |
|------|------|
| 量 | 字数/条数/时间跨度 |
| 多样性 | 是否覆盖工作+生活+情绪+决策等多场景 |
| 私密度 | 是公开文字还是私下对话、日记（私密材料信号更强） |
| 时间跨度 | 一天 vs 一周 vs 一个月 vs 更长（跨度越大越能区分人格底色和阶段状态） |
| 情绪密度 | 有没有负面事件/冲突/挫折/高光时刻（单一情绪色调的材料容易偏） |

### 分析深度分级

| 等级 | 条件 | 能支撑的分析 |
|------|------|--------------|
| S级 | 多场景、跨1个月+、含私密对话+公开文字+工作+情绪事件 | 全部8个框架，高置信度 |
| A级 | 多场景、跨1-2周、有情绪事件 | OCEAN + 荣格 + CBT + 行为地图，中高置信度 |
| B级 | 单场景（如只有工作材料）或跨度 < 1周 | OCEAN部分维度 + 行为地图 + 初步建议 |
| C级 | 几百字/几条消息 | 只能做轻量印象，需标注「置信度有限」 |

### 补充建议模板

根据缺失的维度，给出具体建议：
- 缺情绪材料：「如果有最近让你烦的事、吵过的架、失控的时刻，补进来会让分析更准」
- 缺私密材料：「公开文字看到的是面具多一些，有日记或私聊能挖到更深层的东西」
- 缺时间跨度：「一周内的材料只能看到近期状态，要区分人格底色需要更长跨度」
- 缺工作场景：「加上工作相关的材料（对话/复盘/任务安排），能更准地看到尽责性和决策模式」

## 对比分析（多次使用时触发）

当用户之前做过 self-mirror 分析，且当前对话/memory 中有历史报告时，自动触发对比模式。

### 触发条件

- memory 或历史对话中存在之前的自我画像报告
- 用户说「再分析一次」「看看我最近有没有变化」「跟上次比呢」
- 或者距离上次分析超过2周，用户再次请求分析

### 对比输出结构

在正常报告之后，追加一节「变化追踪」：

---

**变化追踪（对比上次：[上次日期]）**

| 维度 | 上次 | 这次 | 变化方向 | 说明 |
|------|------|------|----------|------|
| 例：尽责性 | 中高（收尾有阻力） | 中高（阻力减少） | ↑ | 5月发了3篇，比4月快 |

**明显变化（2-3条）：**
- 变化1：上次怎样 → 现在怎样 → 这意味着什么
- 变化2：...

**没变的（1-2条）：**
- 哪些是稳定人格底色，预计不会变
- 哪些是卡点没有松动，需要继续关注

**下一次分析建议：**
- 建议什么时候再做一次（1周/2周/1个月）
- 到时候重点观察什么

---

### 对比注意事项

- 不要把所有维度都对比，只挑有明显变化的和用户关心的
- 不要虚构变化——如果材料不足以判断变化，直接说「这个维度两次材料不可比」
- 变化不等于进步——有些变化是中性的或阶段性的，不要硬说好或坏
- 稳定不等于没用——如果某个维度两次都一样，可以升级为「确认的人格底色」，置信度提高
